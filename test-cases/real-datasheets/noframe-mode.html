一、为什么需要无框模式

真实厂商图的四个特征，把原来的几何解析器全堵死了：

障碍实测证据后果
没有「每条信号一个方框」AD7606 / ISSI / ADS8482 全部如此 find_tracks 靠配对边框分行 → 直接失效
长横线 ≠ 电平轨ISSI 图上检出 16 条「长横线」，其中3 条是底部 tRCD/tRRD 标注尺寸线、11 条是总线带边界与阴影区边界，真电平轨只有 1 条 按「长横线」分行会分出完全错误的行
电平平台可能太短AD7606 Fig4 的 RD 低电平平台只有 ~150px < 10%W(201px) 阈值 整条 RD 轨漏检
边沿是斜坡不是直角ADI 图所有跳变边沿宽约 25px 「机绘正交波形」这个前提部分失效

二、无框模式怎么做的（三步，全确定性）

1用行标签文字块分行

把左侧标签列里的深色像素做 y 方向投影，一段文字 = 一条信号行。

关键坑：必须先剔掉竖外框列 —— 外框每一行都是深的，会把所有文字带粘成一条。实测 ISSI 不剔除时 8 条带 → 1 条，全错。

2用长横段定波形区左右界

所有「长横向深色段」中，起点的最小值 / 终点的最大值。

关键坑：必须排掉近全宽的横线（图的外框就是最长的那条横线，起点在最左）。实测 ISSI 不排除时误得 [16,2916]，正确是 [356,2878]。

3用灰底填充判「电平 vs 总线」

厂商画总线带 / 无效区习惯铺一层中灰，电平信号是纯白底。

阈值 0.05：ISSI 行0 CLK = 0.019，行1–7 总线带 = 0.101 ~ 0.287（5~15 倍分离）；AD7606 Fig2 五行电平 0.005~0.015，零误报。

刻意选的保守方向

拿不准时报 level：多解一行，工程师一眼看出是垃圾删掉即可；
报错成 bus 会静默丢信号，代价大得多。

已知局限：AD7606 的 DB[15:0] 总线带是白底黑边（不铺灰），检不出来 —— 属于「解得不完美」而非「丢数据」。要精确控制就用 --rows level,level,bus,level。

五、能力边界（写在明处）

✓ 能做到

  • 无框图上自动分行 —— 4/4 精确命中，行数、顺序、位置全对
  • 自动定位波形区左右界 —— 两套独立方法（空白走廊 / 长横段）在 ISSI 上互相印证，都是 x=356
  • 自动认出时钟轨道，解出周期与位窗
  • 对占空比不敏感 —— 自测图 SCLK 是 41%/59% 不对称占空比，用「全周期」口径仍判对
  • 无时钟的图直接报错，不硬凑假时钟输出垃圾

✗ 不能做到（需模型或人工）

  • 认信号名：标签是文字，几何只知其位置不知其内容 → 需要 OCR 或模型
  • 读总线文字：ACTIVE / NOP / WRITE / Din m 这些值只能识别形状位置，读不出字
  • 选通型异步接口：AD7606 Fig4 / Fig2、ADS8482 Fig33 全是 CS/RD 脉冲控制，本来就没有时钟，而本工具按「时钟周期 = 位窗」设计 → 不适用（已能正确报错拦下）
  • 斜边电平：ADI 图的斜坡边沿会让边缘 1–2 个位窗的采样落在坡上
  • 轴断裂：图中间的省略号符号代表时间被压缩，跨断裂点的周期无意义
  • 白底黑边的总线带：灰底判据检不出来

六、这如何改变整条链路

原来的问题不是「要不要用模型」，而是「让模型干它擅长的哪一段」。三层架构：

层输入判据做什么成本
L0 分流是不是机绘波形图决定走几何还是走模型0
L1 几何机绘正交/斜边波形图分行 → 定位位窗 → 采样电平 → WaveJSON0 token，可复现
L2 模型兜底L1 失败 / 需要语义只做几何做不到的三件事：认信号名、读总线文字、判省略号。**不再让模型去数电平**极小

关键点：让模型「数电平」是用它的短板（本项目铁律 1 之所以存在，就是因为模型老把 2-9 当成电平）。而 L1 先把图切成 N 个单信号条带之后，模型的任务就从「数电平」降级为「认几个字」。

七、怎么用

# 无框模式（真实 datasheet 默认走这条）
python3 scripts/auto_trace.py --png datasheet-fig.png --verbose

# 手工指定每行类型（自动判不出白底总线带时兜底）
python3 scripts/auto_trace.py --png fig.png --rows level,level,bus,level

# 强制要求每条信号有独立方框（老行为）
python3 scripts/auto_trace.py --png fig.png --mode frame

# 自检（56 项，含无框模式 13 项）
python3 scripts/selftest.py
